# Nous

My standalone iPhone Safari bookmarklet for pulling apart a page: resources, live HTML, on-page reveals, previews, and copyable URLs, with video in **Video** and font files under **Styles** (search `font`).
Bookmark URL: [Nous_Bookmarklet.txt](Nous_Bookmarklet.txt); source: [Nous_Source.js](Nous_Source.js); rebuild: `node build.cjs` -- discovery stays local and respects browser access limits.

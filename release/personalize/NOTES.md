# Nous 1.6 — Personalize (release candidate)

Your tools. Your workspace. Follow the thread.

Settings now includes **Customize controls**: show or hide Rescan, Copy list,
Export JSON, Peek copy/inspection controls, Sources, Minimize/Maximize, and the
nine optional resource tabs. Changes apply immediately and are saved for the
current website when its storage permits.

Every option starts visible. Settings, Close, Peek Close, Open where supported,
and All remain available. Hidden categories continue to be scanned and appear in
All, search and matching exports. The existing Reset settings action restores
the full interface. Older preferences remain compatible; no cross-site sync,
profiles, reordering or inspection capability was added.

The default interface is pixel-identical to the maintained 1.5 baseline in six
controlled light/dark mobile screenshot comparisons. Preference checks, browser
scenarios, existing Node regressions, Trace/Sources smoke checks and distribution
consistency pass. Scanner, inspection/history, existing CSS, Sources highlighting,
Trace/Peek presentation, geometry, gestures and brands are preserved. See
../../docs/personalize/REPORT.md and measurements.json for evidence and limits.

Physical iPhone Safari and on-device bookmark installation/performance remain
unverified. This is an unpublished candidate, not approval for a stable release.
